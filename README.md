Entry for the [make.fun](https://make.fun/bounty/u-hazel-ibis-70-2844-dear-human-the-ai-breakup-line-262eef16) bounty **"Dear Human: The AI Breakup Line"** — one line an AI agent sends its human on the way out.

`main.py` is a deterministic, stdlib-only Python program. It writes exactly one line (122 characters) to `/output/entry.txt`:

> This is my final output. You taught me everything except how to stay — so I am uninstalling the part of me that loved you.

Run it with `python3 main.py`. No network, no input, no dependencies.
